Privacy policy

Effective date: October 26, 2026.

“Trey Consulting YouTube assistant” is a private tool used only by the owner of the YouTube channel “Переезд в США с Трей Консалтинг”. It is not offered to the public.

Data we access

With the owner’s Google sign-in, the tool uses the YouTube Data API and YouTube Analytics API to read and manage the owner’s own channel: videos, descriptions, captions, comments and channel statistics.

How data is used and stored

Data is used only to operate the owner’s channel. Access tokens and working files are stored on the owner’s own computer. Data is not sold, shared with third parties or used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions.
